Infinite UI Demo

Infinite UI is a collection of reusable components for building elegant user interfaces in Go.
It is built with a-h/templ, Alpine.js, Tailwind CSS, Phosphor Icons and the occasional additional JavaScript libraries when necessary.

.FileUploadInput

A drop zone with click-to-pick. It lists each file with its type icon, size, and a remove button, and rejects files that break the size, count, or type limits. The files submit with the form under InputName. During an HTMX request, each file shows its own upload progress.

Usage 

<form hx-post="/api/v1/files/" hx-encoding="multipart/form-data" hx-swap="none">
	@uiForm.FileUploadInput(uiForm.FileUploadInputSettings{
		InputName: "archiveFiles",
		Label:     "Drop archives here or click to pick",

		// OptionalFields
		Description:      ".tar, .zip, .xz, or .br up to 5 MiB, 3 files at most",
		AcceptedTypes:    []string{".tar", ".zip", ".xz", ".br"},
		MaxFileCount:     3,
		MaxFileSizeBytes: 5242880,
	})
</form>
Set hx-encoding="multipart/form-data" on an HTMX form, or enctype="multipart/form-data" on a native form. The limits run in the browser only, so the server must check them again.

Live Example

Pick or drop up to three archives. The demo endpoint keeps the files in the browser and replays the upload progress over two seconds.

.RemoteSearchableSelectInput

A remote searchable select fetches its options from a URL as the user types. It debounces the requests, waits for the minimum query length, discards stale responses, and shows loading, empty, and error states. The endpoint receives the query in the parameter named by OptionsQueryParam and returns { body: [{ label, value }] }.

Usage 

@uiForm.RemoteSearchableSelectInput(uiForm.RemoteSearchableSelectInputSettings{
	InputName:       "country",
	Label:           "Country",
	OptionsUrl:      "/api/countries/search",
	TwoWayStatePath: "country",
})
Alpine.js Parent State (x-data)
<div x-data="{country: ''}"></div>

Live Example

A single select over a demo endpoint that answers after a short delay, so the loading state is visible.

.Chart

A chart renders line, area, bar, and donut charts with Vega. It draws an HTML legend, a hover tooltip, and a screen-reader table, and it redraws when the rows at RowsOneWayStatePath change. The page must load Vega once, usually with @uiImport.HeadTagsVega() in the layout head.

Usage 

@uiDisplay.Chart(uiDisplay.ChartSettings{
	Type: uiDisplay.ChartTypeArea,
	XAxis: uiDisplay.ChartXAxisSettings{
		RowKey:          "time",
		ScaleType:       uiDisplay.ChartScaleTypeTime,
		TickLabelFormat: "%H:%M:%S",
	},
	Series: []uiDisplay.ChartSeriesSettings{
		{RowKey: "cpu", Label: "CPU"},
		{RowKey: "memory", Label: "Memory"},
	},

	// OptionalFields
	Cartesian: uiDisplay.ChartCartesianSettings{
		YAxis: uiDisplay.ChartYAxisSettings{
			TickLabelFormat: ".0%",
			MinValue:        "0",
			MaxValue:        "1",
		},
	},
	Tooltip:             uiDisplay.ChartTooltipSettings{TitleFormat: "%H:%M:%S"},
	RowsOneWayStatePath: "resourceUsageRows",
	MaxRows:             20,
})
Alpine.js Parent State (x-data)
<div x-data="{resourceUsageRows: [{time: 1760360000000, cpu: 0.42, memory: 0.61}]}"></div>

Live Example

CPU and memory usage. The parent state appends a row every two seconds and drops the oldest.
