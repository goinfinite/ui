JavaScript utilities embedded as the UI toolset. Each file owns one concern; import.templ concatenates them into a single minified script.

## Summary

- alpineState.js — Alpine.js state registration helper
- apiResponse.js — API response message and outcome resolution
- index.js — public UiToolset namespace assembly
- jsonAjax.js — JSON fetch client with payload validation, overlay request counting, and toast integration
- loadingOverlay.js — loading overlay visibility control
- randomPassword.js — random password generation
- selectDropdown.js — shared open-upward decision for select-style dropdowns; measures the space above and below the trigger up to the viewport and every clipping ancestor, and the shared dropdown controller that drives the open with checked-row focus, the close with focus return, the commit, and the arrow-key move between options for every custom dropdown, which keeps navigation working where the options carry no radio name and so form no native group
- unixTimestamp.js — UnixTimestamp.ToIsoDate and UnixTimestamp.ToRfc1123; both take Unix seconds, format in UTC, and throw InvalidUnixTimestamp on a non-number or a UTC year outside 0000-9999

## Guidance

- SHOULD keep one concern per file
- SHOULD keep index.js last in the import.templ concatenation, so the reader reaches the public API after its parts
- SHOULD state the timestamp unit in the helper name or its docs: UnixTimestamp helpers take seconds, the unit the Infinite APIs return
