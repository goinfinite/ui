Display components for presenting content and creating layouts. These are primarily presentational; state management is optional for components like modals and toasts.

## Summary

- README.md — Component list and usage snippets for the package
- accordion.templ — Collapsible section component for grouping content, with an optional single-open mode, an option that renders the first item open, and a shared TextCase title transform

## Constraints

- MUST support nested templ.Component for content composition
- MUST use Phosphor icons for visual elements
- MUST support various size and styling variants
- MUST keep the Vega view and the resize observer out of the chart Alpine state: Alpine proxies every nested object of reactive state, and a proxied Vega view hangs the page
- MUST build chart specs for plain Vega only; the import package no longer loads Vega-Lite or vega-embed
- MUST take chart colors as Tailwind tokens and resolve them through the rendered probes; Vega needs real CSS colors, and the UnoCSS runtime only styles classes it finds in the page
- MUST normalize every probed chart color to sRGB through a canvas: a host page on Tailwind v4 or UnoCSS preset-wind4 computes tokens to oklch, which Vega cannot parse
- MUST give every chart color a fallback: an unresolved token would otherwise reach Vega as undefined and draw black or nothing
- MUST keep the JSON tags on the private chart wire structs, never on the public settings structs: the public structs hold HTML-only fields and Go callbacks that must not reach the client
- MUST truncate the CollapsibleText in JS against the measured line budget with the affordance inline: the affordance must share the last text line after the ellipsis, and the truncation must re-run through the width-aware ResizeObserver because the text re-wraps with the container
- MUST paint the progress fill from the first threshold whose MinimumPercent the current percent has reached, so callers list thresholds from highest to lowest and the built-in ladder keeps its descending order
- MUST keep the chart type dispatch ahead of every Vega settings resolver: the progress type skips XAxis, Series, Vega, and the color probes, and only the templ branch decides this
- MUST keep the chart orientation mapping in the spec builders, not in the settings: XAxis always names the category axis and Cartesian.YAxis always names the value axis, whatever the Vega scale names become
- MUST format the progress percent the same in the static render and the bound render: one decimal in the label and the width; MUST report the clamped value, never the percent, in aria-valuenow with two decimals, because aria-valuemin and aria-valuemax carry the value bounds
- MUST reject a gauge band whose percents leave the 0-100 range or whose minimum is not below its maximum: the arc math assumes an increasing, in-range span
- MUST grow the gauge viewBox with the text offset and the larger of the two text sizes, and widen it for a long value or label, or the SVG clips the center text a caller moved or enlarged
- MUST keep the gauge arc centerline at the outer radius minus half the ArcThickness and draw the ticks in the resolved position: the track and every band must share one outer edge, the outside ticks widen the viewBox to keep their labels in view, the full-circle inside ticks label the top half only so the center text keeps its space, and the full-circle value and label must sit below the pivot, where at rest the text sat on the pivot and the needle shaft
- MUST label a radial bar with its share of the largest value and a sunburst arc with its share of the total or of its category: the ring geometry gives each arc a different whole, and one label each keeps the chart readable
- MUST place waffle cells on rounded cumulative category boundaries so the categories tile every cell: per-category rounding drifts from the cell total
- MUST hang every sunburst category under one synthetic root row and tag the hierarchy rows with a numeric leaf flag: the Vega stratify transform allows one root and rejects a missing one, and its aggregate min turns empty strings into undefined, so a string test cannot mark leaves

## Guidance

- SHOULD support Alpine.js for interactive components (modal visibility, toast dismissal)
- SHOULD include optional left and right icons for alerts and badges
- SHOULD accept a shared uiToolset.TextCase value on components with labels or titles (Accordion, HeaderBlock, Tag)
- SHOULD provide both HTML and state-based binding options for content
