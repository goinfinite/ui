Display components for presenting content and creating layouts. These are primarily presentational; state management is optional for components like modals and toasts.

## Summary

- README.md — Component list and usage snippets for the package
- accordion.templ — Collapsible section component for grouping content, with an optional single-open mode and a shared TextCase title transform
- alert.templ — Alert/notification box with title, description, and icon variants (success, warning, error, info)
- cloakLoading.templ — Overlay to hide content while loading
- confirmationDialog.templ — confirmationDialog engine plus the ConfirmDialog, WarningDialog, CriticalDialog, and DeleteDialog presets; delete and critical gate the confirm action behind typing the target name or id
- confirmationDialog.go — Tone resolver, target match path resolver, the type-to-confirm field label resolver, and the type-to-confirm disabled expression builder
- confirmationDialog_test.go — Table-driven tests for the tone, match path, and disabled expression helpers
- headerBlock.templ — Header block (title, sub-heading, icon, actions) with the HeaderSize scale, left or top icon placement, and a shared TextCase transform
- headerIcon.templ — Icon chip with color, background, padding, and radius settings
- loadingOverlay.templ — Full-screen overlay with loading indicator
- modal.templ — Dialog/modal component with header, content, footer, the viewport-percentage InitialSize scale that sets width and height together, the WidthPercent and HeightPercent overrides, the PossibleSizes enlarge and reduce range, the content-height option, and the middle-content scroll toggle
- tag.templ — Badge/label component for categorization with a bound value display, a tiny size for table cells, a shared TextCase label transform, and an optional remove button
- toast.templ — Dismissible notification component with Alpine.js state management
- toastState.js — Alpine toast state with API response message display and HTMX handling

## Constraints

- MUST support nested templ.Component for content composition
- MUST use Phosphor icons for visual elements
- MUST support various size and styling variants

## Guidance

- SHOULD support Alpine.js for interactive components (modal visibility, toast dismissal)
- SHOULD include optional left and right icons for alerts and badges
- SHOULD accept a shared uiToolset.TextCase value on components with labels or titles (Accordion, HeaderBlock, Tag)
- SHOULD provide both HTML and state-based binding options for content
