Go-side utilities for code generation and content transformation. Uses esbuild to minify JavaScript and CSS at compile time or runtime. Also hosts the shared text-case values, the shared token-to-class style resolvers, and the shared hover tooltip state and surface classes.

## Summary

- README.md — Component list and usage snippets for the package
- minifier.go — Wrapper around esbuild API for minifying JavaScript and CSS content, with options for whitespace, identifiers, and syntax minification
- minifier_test.go — Tests for the minifier utility
- textCase.go — Shared TextCase values (none, lower, upper, capitalize) and the class resolver used by components that expose a text-case setting
- styleTokens.go — Shared token-to-class resolvers: background, text, and border color, border radius, shape, shadow, ring thickness, ring (regular and compact), padding (regular and compact), and gap. The single-token resolvers take the fallback class the caller wants for an empty or unknown token; `RingClassResolver` pairs a color with a thickness and returns an empty string when either is missing; `CompactRingClassResolver` pairs them too, keeps `ring-1` when the thickness is empty, and returns an empty string when the color is empty
- styleTokens_test.go — Table-driven tests for the shared token-to-class resolvers including the fallback class
- tooltip.go — The embedded tooltipState.js once-handle that components render, TooltipSurfaceClassesResolver (the shared fixed-layer tooltip class string, with optional min/max width and height caps and a default max width), and the shared TooltipPosition* placement values
- tooltip_test.go — Tests for the shared tooltip surface classes
- tooltipState.js — Alpine data component that teleports a tooltip to the document body, positions it with fixed coordinates on hover or focus, and flips it to stay inside the viewport; waits 200ms before it reveals so a passing pointer does not flash it; attaches its scroll and resize listeners only while the tooltip is visible; shared by the Button, the CarouselItemTooltip, and the InputHint
- componentIdPrefix.go — The ComponentIdPrefixGenerator that mints a unique per-render id prefix from a component name and a counter, used by the tabs and the accordion
- componentIdPrefix_test.go — Tests for the id prefix generator uniqueness and component name
- componentIdHash.go — HashComponentIdParts, the stable hash of the inputs that identify a refreshing component, used by the carousel and the data table to keep their id across renders
- componentIdHash_test.go — Tests for the id hash stability and part sensitivity

## Constraints

- MUST support both JavaScript and CSS content types
- MUST gracefully fall back to unminified content if esbuild errors occur
- MUST return pointers to strings for memory efficiency
- MUST keep tooltipState.js declarations inside the RegisterAlpineState callback: a second embed in a new render context (an HTMX fragment) must not redeclare a top-level const, which aborts the script with a SyntaxError
- MUST keep the radius token mapping aligned with the class suffix (`md` renders `rounded-md`, `full` renders `rounded-full`) so one token means one class in every component

## Guidance

- SHOULD provide convenience functions (MinifierJs, MinifierCss) with sensible defaults
- SHOULD offer templ.Component wrapper functions for inline rendering
- SHOULD support configurable minification settings via MinifierSettings struct
